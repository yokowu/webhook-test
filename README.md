# Webhook Test Project

This project is designed for testing webhooks. It provides a simple setup to receive and inspect webhook payloads.

## Services

- MySQL
- PostgreSQL
- Redis

## Setup

1. Clone the repository.
2. Run `docker-compose up` to start the services.
3. Configure your webhook to point to the appropriate service endpoint.

## Usage

- Send webhook payloads to the service endpoints.
- Inspect the received payloads to verify the webhook functionality.
